This is a Minecraft ai helper bot that can make a lot of things.

###   Setup Base-2 with using api key
1. Download the Base-2
2. Unpack .zip (if you download .zip)
3. Edit in file bot.js the **ip** and **port** for you.
4. Come to https://groq.com/ and create account
5. Now, come to 'Developers/Free API key' on https://groq.com/
6. Create new API key and **copy it**
7. Return to downloaded bot and select model that you need (ex. llama-3.3-70b-versatile.py)
8. Edit in this selected file: "PASTE_YOUR_API_TOKEN" > Your API key
9. Start bot.

###   Setup Base-3 without using api key
1. Download the Base-3
2. Run dashboard.js

<br>Note: Base-3 **can't analize messages from minecraft chat and don't have chat**

###   Comparing Base-2 and Base-3
**Base-2**
- Simple: Not dashboard or terminal, Chat analizing.
- Chat and commands: Can chat with players and smart analize chat.
- Repeat command: Bot can't loop actions.
**Base-3**
- Private: Can select setted bot name
- Dashboard: Completely Terminal that control bot.
- Just write command: You don't need to send a lot of messages to set bot goal, just write needed action in Terminal and goal setted for 24/7.
